空中飞鼠 启用后，抬起手机指向电视即可控制指针。

只需设置一次：信任这台电视的局域网证书后，空中飞鼠就能安全连接。

为 iPhone 安装信任描述文件

安装后前往“设置 → 通用 → 关于本机 → 证书信任设置”，开启 AirMouse 证书的完整信任。

下载电视证书（.cer）

下载后在“设置 → 安全 → 加密与凭据 → 安装证书”中选择 CA 证书，再回到此页。
